# Эмулятор «Мафия»

Проект для задания 1. Требуется компилятор с поддержкой C++20 и CMake 3.20+.

## Сборка

```sh
cmake -S . -B build
cmake --build build
```

План выполнения и выбранный минимально затратный маршрут к баллам находятся в [PLAN.txt](PLAN.txt).

## Запуск

```sh
./build/mafia --players 10 --interactive --open-announcements --full-log
```

По умолчанию игра запускается с 10 игроками и читает `config.yaml` из текущей
рабочей папки. Другой файл выбирается параметром `--config FILE`.
Поддерживаемый формат конфигурации:

```yaml
extra_roles:
  - Ninja
  - Bull
  - Elder
```

Если при малом числе игроков для дополнительной роли не хватает места, игра
выводит предупреждение и пропускает эту роль.

## Локальный AI-агент

AI работает локально через Ollama и модель `qwen2.5:3b`. API-ключ и интернет во время игры не нужны.

На Ubuntu/Debian установите зависимости проекта:

```sh
sudo apt install libcurl4-openssl-dev nlohmann-json3-dev
```

Установите Ollama, затем один раз скачайте модель:

```sh
ollama pull qwen2.5:3b
```

Запуск AI-игрока:

```sh
./build/mafia --players 10 --ai-player 2 --full-log
```

Если Ollama не запущена или вернула некорректный ответ, игра автоматически
использует обычные `discuss()` и `vote()` для этого игрока.
